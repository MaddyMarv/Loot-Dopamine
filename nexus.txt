Displays floating combat text when picking up crafting materials. Includes customizable colors, positioning, and a session totals counter.

[b]Mod Settings / Commands:[/b]
[spoiler]
[b]General[/b]
- Disable Base Game Notification
- Show Totals Display
- Enable Shake Effects
- Floating Text Options (X/Y Offset, Transparency, Text Size [Largest, Large, Default, Small])

[b]Colors[/b]
- Material Text Colors (Plasteel, Diamantine, Salvage, Scrap, Event Material)
[/spoiler]
